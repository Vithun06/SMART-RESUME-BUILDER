# 📄 Smart Resume Builder

An interactive full-stack web application that enables users to input profile details, build structured ATS-friendly resumes, and generate live PDF downloads.

---

### 🚀 Key Features
* **Dynamic Resume Form:** Modular input forms for personal details, education, skills, work experience, and projects.
* **Real-Time Preview:** Live rendering of formatted resume structure as data is entered.
* **ATS-Friendly Formatting:** Clean design layout structured to easily pass Applicant Tracking Systems.
* **PDF Export & Storage:** Seamless PDF document downloading and secure cloud integration.

---

### 🛠️ Tech Stack
* **Frontend:** React.js, Tailwind CSS / CSS3
* **Backend:** Node.js, Express.js
* **Database & Hosting:** Supabase, Firebase
* **Build Tool:** Vite
